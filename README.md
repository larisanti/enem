# Análise de Desigualdades Socioeducacionais no ENEM (2022-2023) em Curitiba

Projeto está sendo desenvolvido como requisito para a disciplina de "Atividades Extensionistas" do curso de Engenharia de Software (Uninter).

Objetivos do projeto:
I – Extrair, tratar e analisar os microdados do ENEM referentes às edições de 2022 e
2023 para o município de Curitiba (PR), utilizando a linguagem Python.
II – Avaliar a influência do tipo de escola (pública, privada e egressos) e do nível
socioeconômico sobre o desempenho dos participantes nas cinco competências
avaliadas.
III – Desenvolver e disponibilizar um dashboard voltado a cursinhos solidários e
estudantes de Curitiba.
IV – Contribuir com informações para futuras discussões sobre políticas públicas
educacionais voltadas à redução das desigualdades de aprendizagem em Curitiba.
